# 応募の集計と抽選

## 応募者の集計

ゲストからの応募を集計できます。応募の入力元は複数に対応しています。

- **VER-Lib 上での応募** — Web からの応募と、先行予約を集計します。
- **外部 CSV の取り込み** — 列の対応づけを指定して、CSV から応募者を登録します。

## 抽選

集めた応募者に対して、公平な抽選を実行し、当選・落選を決定します。

- **インスタンス定員** — インスタンスごとの当選人数を設定できます（固定人数のほか、スタッフ数に連動させることもできます）。
- **連続落選者への救済措置** — 過去に連続して落選しているユーザーの当選確率を優遇できます。
- **除外設定** — ブラックリストのほか、Discord のロール / ユーザー、VRChat ユーザー、グループのロール / 全メンバー、連携サーバーの参加者を抽選から除外できます。

```{note}
同じ抽選アクションを再実行しても、**すでに抽選済みのインスタンスはスキップ**され、結果は上書きされません。
結果を変えたい場合は **再抽選** アクションを使うと、まだ承諾していない当選者を辞退扱いにして、空いた枠だけを抽選し直せます。
```
