# Looker Studio で応募履歴を読む

グループの **ゲスト応募履歴** を、Google の **Looker Studio** のデータソースとして読み込めます。VER-Lib が提供するコネクタと、グループの API キーを使います。

## 事前に用意するもの

- グループの **管理者 / オーナー** 権限（権限については「[グループの準備と管理](02_group_setup.md)」を参照）。
- Looker Studio を使う Google アカウント。
- グループの **API キー**（次の手順で発行します）。

## API キーを発行する

1. グループ画面の「**API キー管理**」を開きます。
2. 「API キーを発行」から、あとで用途が分かる名前（例: Looker Studio 連携）と有効期限を指定して発行します。
3. 表示されたキーをコピーして、安全な場所に保存します。

```{note}
API キーは、発行時に **一度だけ** 表示されます。閉じると二度と表示できません。
キーは読み取り専用で、発行したグループの応募履歴だけを読めます。
```

## Looker Studio に接続する

1. 次のリンクを開きます（VER-Lib のコネクタが Looker Studio で開きます）。

   ```text
   https://lookerstudio.google.com/datasources/create?connectorId={{LOOKER_CONNECTOR_DEPLOYMENT_ID}}
   ```

   % 運営メモ: {{LOOKER_CONNECTOR_DEPLOYMENT_ID}} は、コネクタを deploy した後のデプロイ ID に差し替える（手順は event-manager-looker-connector の README）。

2. 初回は Google の確認画面が表示されます。内容を確認して「承認」します。
3. 認証情報の入力欄に、発行した **API キー** を貼り付けて送信します。
4. 設定欄を入力します。
   - **グループ ID**（必須）— API キーを発行したグループの ID。グループ画面の URL（`/groups/<グループ ID>/…`）に含まれます。
   - **取得開始日時**（任意）— この日時以降の応募だけを読み込みます。`2026-01-01`（日本時間 0 時）の形式で入力できます。空欄なら全期間です。
   - **日時の表示タイムゾーン** — 日本時間 / UTC から選びます。
5. 「接続」を押すと項目の一覧が表示されます。「レポートを作成」から表やグラフを作成できます。

## 読み込まれるデータ

1 行は **「1 件の応募 × 1 つの質問」** です。質問が 3 つあるフォームへの応募は 3 行になります（質問は列ではなく行として並ぶため、フォームを変更してもデータソースを作り直す必要はありません）。

| 項目 | 内容 |
|---|---|
| 応募ID / セッションID / シリーズキー | 応募・セッション・シリーズを識別する ID |
| セッション名 / 開始日時 | 応募先のセッション |
| ユーザーID / 表示名 / VRChat ID (自己申告) | 応募者（VRChat ID は応募時に本人が入力したもので、確認済みの値ではありません） |
| 応募経路 / 応募状態 / 応募日時 | 応募の状態（`applied` / `cancelled`。取り消した応募も含まれます） |
| 当選状態 / 承諾日時 / インスタンス名 | 当選の状態（`当選` / `辞退` / 空欄。空欄は「未抽選」と「落選」の両方を表します） |
| 質問ID / 質問 / 回答種別 / 回答 | 質問ごとの回答（複数の値は `;` 区切り） |
| 取得打ち切り | 読み込みが途中で打ち切られたときに `true`（下記「制限」を参照） |

## 制限

- API キー 1 本あたり **1 分間に 60 リクエスト** まで読み込めます（1 リクエストで最大 500 行）。上限に達した場合、コネクタは少し待ってから自動で再試行します。
- 1 回の読み込みは **約 4 分 30 秒** で打ち切られます（Google 側の実行時間の上限が 6 分のため）。打ち切られた場合も、それまでに読み込めた行は表示され、「取得打ち切り」が `true` になります。応募件数が多いグループでは、**取得開始日時** で範囲を絞ってください。

```{warning}
応募履歴には、ゲストのフォーム回答などの個人情報が含まれます。レポートを他の人と共有するときは、閲覧できる人の範囲に注意してください。
```

## API キーを失効させる

「API キー管理」でキーを失効させると、そのキーを使ったデータソースは直ちに読み込めなくなります。新しいキーで読み込みを続ける場合は、Looker Studio のデータソースの「認証情報を編集」から新しいキーを入力し直してください。
