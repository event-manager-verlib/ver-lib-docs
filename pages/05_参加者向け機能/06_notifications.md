# 通知を受け取る

イベントに関する通知は、既定では **Discord のダイレクトメッセージ** で届きます。条件を満たす場合は、設定画面からイベントごとに配信先を Discord のチャンネル / スレッドへ変更することもできます（変更先として選べるのは、自分が管理者で、かつ案内担当の Bot が導入されている Discord サーバーです）。

## 募集開始の通知

募集通知が ON のイベントの募集（応募受付）が始まると、通知が届きます。気になっていたイベントの応募を逃さずに済みます。

```{note}
募集開始の通知は **募集通知が ON のイベントにのみ** 届きます。いいねすると、通知の設定がまだないイベントは募集通知が ON になります。通知が不要なイベントは、OFF にできます。
```

## いいねしたときの募集通知

- いいねすると、そのイベントの通知の設定がまだない場合は、募集通知が **ON**、配信先が Discord のダイレクトメッセージ（個人 DM）になります。すでに設定があるイベントは、いいねし直してもその設定のままです。
- ON / OFF は、設定画面のほか、イベントカードやイベント詳細ページの **「募集通知を受け取る」** トグルでも切り替えられます。トグルは、ログインしていて、そのイベントをいいねしているときに表示されます。配信先の変更は設定画面で行います。
- この仕組みが始まる前からいいねしていて、通知を設定していないイベントは、OFF のままです（自動では ON になりません）。通知が欲しい場合は、設定画面かトグルで ON にしてください。
- 配信先が個人 DM のまま OFF にしたイベントは、設定が残らず、通知の設定がない状態に戻ります。そのため、いいねを取り消してもう一度いいねすると、ON になります。
- ON のイベントには、主催者から、いいねした人向けの案内も届くことがあります。

## 当落の通知

応募したイベントの抽選結果が届きます。イベントによっては、当選後に **承諾（参加確定）の操作** が必要な場合があり、辞退が出た枠は再抽選で埋められます。

```{note}
当落の通知は、主催者がワークフローで通知を設定している場合に届きます。設定されていない場合は通知が届かないことがあります。
```
