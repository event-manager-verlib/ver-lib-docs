# 通知を受け取る

イベントに関する通知は、既定では **Discord のダイレクトメッセージ** で届きます。条件を満たす場合は、設定画面からイベントごとに配信先を Discord のチャンネル / スレッドへ変更することもできます（変更先として選べるのは、自分が管理者で、かつ案内担当の Bot が導入されている Discord サーバーです）。

## 募集開始の通知

購読を ON にしたイベントの募集（応募受付）が始まると、通知が届きます。気になっていたイベントの応募を逃さずに済みます。

```{note}
通知は **購読を ON にしたイベントにのみ** 届きます。「いいね」しただけでは通知は届かないため、通知が欲しいイベントは設定画面で購読を ON にしてください。
```

## 当落の通知

応募したイベントの抽選結果が届きます。イベントによっては、当選後に **承諾（参加確定）の操作** が必要な場合があり、辞退が出た枠は再抽選で埋められます。

```{note}
当落の通知は、主催者がワークフローで通知を設定している場合に届きます。設定されていない場合は通知が届かないことがあります。
```
